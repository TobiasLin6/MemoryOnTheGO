# MemoryOnTheGO 🧠

Living in the hustle of NYC's rapidly evolving tech scene, I constantly struggled with information overload and retaining new concepts. To solve this, I developed MemoryOnTheGO, an app rooted in professional research that leverages techniques like the memory palace to help users organize and lock in knowledge. 

Designed specifically for the Swift Student Challenge, this application moves beyond traditional rote memorization by integrating advanced mnemonic strategies to help users move information from short-term to long-term memory more efficiently.

## 🌟 Key Features

* **Memory Palace Integration:** Dedicated tools to help map digital flashcards to physical locations using the Method of Loci.
* **Active Recall Notification System:** A strategic sequence of periodic reminders designed to interrupt the forgetting curve and solidify memory retention.
* **Intuitive Flashcard Interface:** A clean, minimal environment for frictionless studying and self-quizzing.
* **Progress Tracking:** Visual analytics to monitor your retention rates and quiz performance over time.

## 🛠 Tech Stack & Frameworks

* **Language:** Swift
* **UI Framework:** SwiftUI
* **Key Frameworks:** 
    * `UserNotifications` (for the spaced repetition scheduling)
    * `SwiftData` (for local storage of flashcards, decks, and user progress)
* **Platform:** iOS 17.0+

## 🚀 How to Run the Project

Since this project was built for the Swift Student Challenge, it can be easily run in Xcode.

1.  Download or clone the repository.
2.  Open the `MemoryOnTheGO.xcodeproj` file in Xcode.
3.  Ensure your target simulator is set to iPhone 17 Pro.
4.  Hit the **Play** button (`Cmd + R`) to build and run the application.

*Note: To fully experience the notification sequence, you must grant notification permissions upon the first launch.*
